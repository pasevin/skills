# Skills

My agent skills — installable in Warp, Cursor, Claude Code, Codex, and 60+ other agents via [skills.sh](https://skills.sh).

## Quickstart

```bash
npx skills add pasevin/skills
```

## Skills

| Skill | Category | Description |
|---|---|---|
| [commit](./skills/engineering/commit) | engineering | Conventional Commits with GPG signing, scope selection, and pre-commit validation |
| [cluely](./skills/tools/cluely) | tools | Query and manage Cluely meeting sessions, transcripts, and tags from the terminal |
| [brain-catch-up](./skills/productivity/brain-catch-up) | productivity | Project Brain sweep of Slack, meetings, Notion and GitHub since a date; proposes canvas note updates |
| [brain-meeting-intake](./skills/productivity/brain-meeting-intake) | productivity | Turns a meeting transcript into a Notion meeting log in the project's format, plus note updates |
